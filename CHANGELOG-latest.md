## Strata 0.1.1

- **Search everything from This PC:** typing in the search box on This PC now searches every drive. If [Everything](https://www.voidtools.com/) is running, results are instant; otherwise Strata scans in the background at low priority and shows results as it finds them.
- **Search subfolders:** in any folder, typing still filters instantly; press **Enter** to search that folder and all its subfolders.
- Search results show a **Location** column, can be sorted, opened, renamed, copied, cut and deleted, and the right-click menu has **Open file location**.
- **Fixed:** faint "ghost" minimize / maximize / close buttons behind Strata's own when using the Mica or Acrylic background.
