## Strata 0.1.0 — Phase 1

First test build.

- Custom window with browser-style folder tabs (reorder, duplicate, reopen closed with Ctrl+Shift+T) and Windows 11 snap layouts on the maximize button
- Toolbar with back / forward / up / refresh, a clickable breadcrumb path bar with sibling-folder dropdowns, and type-a-path mode (Ctrl+L)
- Instant filter for the current folder (Ctrl+K), with wildcards
- Sidebar with This PC, pinned folders (color tags, reorder) and drives with free-space bars
- Virtualized file list: Name / Size / Modified / Type, sortable and resizable, choose columns; smooth scrolling; box selection; type-ahead
- Open, copy, cut, paste (interoperates with File Explorer), rename in place, delete to Recycle Bin, permanent delete, new folder / text file
- Full Windows right-click menu plus Open in new tab, Pin to sidebar, Open terminal here, Copy path
- Folders refresh automatically when their contents change
- Themes from the suite (Dark, Light, Midnight, Glass, Ember, Ocean, Follow Windows) with Solid / Mica / Acrylic backgrounds
- Remembers tabs, window size, columns and sort order
