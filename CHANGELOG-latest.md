## Strata 0.3.1

- **Command bar** under the toolbar, like File Explorer: **New ▾** (folder, text document, tab), **Cut**, **Copy**, **Paste**, **Rename**, **Delete** (Shift-click deletes permanently), **Sort ▾**, **View ▾** (details / grid / space, dual pane, preview, sidebar, hidden items, file extensions, version stacking), **Filter ▾**, **Changed ▾**, plus **Undo**, **Select all** and **Properties** on the right.
- Buttons grey out when they can't be used (Paste only lights up when there's something to paste). In a narrow window the labels collapse to icons with tooltips.
- Hide it from View ▾ → Command bar, the ⋯ menu, or Settings → Layout.
